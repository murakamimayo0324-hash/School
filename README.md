# School

学習・作業用リポジトリ。各ブランチに散らばっていた成果物をここに集約しています。

## リポジトリ構成

- `calculator.py` / `test_calculator.py` — 電卓スクリプトとテスト
- `sample.py` — コードレビュー練習用サンプル
- `stopwatch/` — ストップウォッチ Web アプリ(ラップ・保存・キーボード操作・ダークモード対応。詳細は `stopwatch/README.md`)
- `.claude/` — Claude Code の設定(Skills / Agents。詳細は `CLAUDE.md`)

## データ管理ルール

以下のデータは **git 管理せず、ローカルのみで保管** します(`.gitignore` で除外済み)。

| データ | 置き場所(除外対象フォルダ) |
|---|---|
| 顧問先データ | `顧問先データ/`, `顧問先/`, `clients/`, `client-data/` |
| 給与・個人情報 | `給与個人情報/`, `給与データ/`, `給与/`, `個人情報/`, `payroll/`, `payroll-data/`, `personal-info/` |
| 作業ログ | `作業ログ/`, `work-logs/`, `logs/`, `*.log` |

機密ファイルは必ず上記いずれかのフォルダ名の下に置いてください。それ以外の場所に置くと git 管理対象になります。コミット前に `git status` で意図しないファイルが含まれていないか確認する運用を推奨します。
