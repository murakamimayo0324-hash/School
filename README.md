# ⏱ ストップウォッチ Web アプリ

ブラウザで `index.html` を開くだけで動作する、単一ファイルのストップウォッチです。
外部ライブラリ・ビルド・サーバーは一切不要です。

![形式](https://img.shields.io/badge/format-single%20HTML-38bdf8) ![deps](https://img.shields.io/badge/dependencies-none-22c55e) ![theme](https://img.shields.io/badge/theme-dark-111a2e)

---

## 起動方法

追加インストールは不要です。次のいずれかで開けます。

- **ダブルクリック**: `index.html` をファイルマネージャーでダブルクリック
- **ブラウザにドラッグ&ドロップ**: `index.html` をブラウザウィンドウに落とす
- **コマンドから開く**:
  ```bash
  # macOS
  open index.html
  # Windows
  start index.html
  # Linux
  xdg-open index.html
  ```

> ネットワーク接続やローカルサーバーは不要です。オフラインでもそのまま動作します。

## 基本操作

| ボタン | 動作 |
|--------|------|
| **スタート / ストップ** | 計測を開始・停止します。停止しても経過時間は保持され、再度スタートで続きから再開します。 |
| **ラップ** | 計測中に、その時点の時間を記録します（計測中のみ有効）。 |
| **リセット** | 経過時間を `00:00.000` に戻し、ラップ記録もすべて消去します。 |

### 時間表示の形式

時間は **`分:秒.ミリ秒`**（`MM:SS.mmm`）で表示されます。

```
00:07.248
└┬┘ └┬┘ └┬┘
 分   秒  ミリ秒
```

- ミリ秒はシアン色で強調表示されます。
- 計測は `performance.now()` を基準にしているため、タブが重くても時間がずれにくい設計です。

## 拡張機能

このアプリには 4 つの拡張機能が実装されています。

### 1. ラップ（区間計測）

計測中に「ラップ」を押す（またはキーボードの `L`）と、画面下部の **ラップ記録** に 1 行追加されます。
各行には次の 3 つが表示されます。

| 表示 | 意味 |
|------|------|
| `ラップ N` | ラップ番号 |
| `+MM:SS.mmm` | 直前のラップからの **区間タイム（スプリット）** |
| `MM:SS.mmm` | スタートからの **累計タイム** |

記録は押した順（＝時間順）に上から下へ並びます。

### 2. localStorage による自動保存

経過時間とラップ記録は、ブラウザの `localStorage` に **自動保存** されます（タイトル横の「💾 自動保存」バッジが目印）。

- ページを **再読み込み** したり、**ブラウザを閉じて開き直し** ても、前回の記録が復元されます。
- 復元されると画面上部に **「前回の記録を復元しました（localStorage）」** と表示されます。
- **リセット** を押すと、保存データもクリアされます（次回開いたときは白紙の状態）。

> 保存先は開いているブラウザのローカル領域のみです。サーバーには何も送信されません。

### 3. キーボード操作

マウスを使わずに操作できます。

| キー | 動作 |
|------|------|
| `Space` | スタート / ストップ |
| `L` | ラップ |
| `R` | リセット |

画面下部にショートカットのヒントが常時表示されます。

### 4. ダークモード

計器風のダーク配色（ネイビーのグラデーション背景＋シアンのアクセント）で表示されます。
目に優しく、時間表示が読み取りやすいデザインです。

## 動作確認

主要ブラウザ（Chromium 系 / Firefox / Safari）で動作します。
`index.html` を開き、次を確認できます。

1. 開くだけで `00:00.000` が表示される
2. スタート → 時間が進む / ストップ → 停止して値を保持
3. `分:秒.ミリ秒` 形式で表示される
4. ラップで時間が記録され、時間順にリスト表示される
5. リセットで表示とラップ記録の両方がクリアされる
