## タスク

指定されたファイルを読み込み、内容を要約してください。

対象ファイル: $filepath

## 手順

1. Read ツールで `$filepath` のファイルを読み込む
2. 内容を分析し、以下の出力形式に従って日本語で要約を出力する
3. ファイルが存在しない場合は、その旨を伝えてパスの確認を促す

## 出力形式

必ず次の構成で出力すること:

# タイトル
（ファイル全体の内容を一行で表すタイトル）

## トピック
1. （重要なトピック 1 とその簡潔な説明）
2. （重要なトピック 2 とその簡潔な説明）
3. （重要なトピック 3 とその簡潔な説明）

## 結論
（ファイル全体から導かれる結論・要点を 1〜3 文でまとめる）

## 注意事項

- トピックは必ず 3 つ挙げること
- 要約はファイルに書かれている内容のみに基づくこと（推測で補わない）
- コードファイルの場合は、目的・主要な処理・依存関係の観点でトピックを選ぶこと
