## タスク

指定されたファイルを読み込み、内容の要約と改善提案を出力してください。

対象ファイル: $filepath

## 手順

1. **ファイル読み取り**: Read ツールで `$filepath` のファイルを読み込む
2. **要約作成**: 内容を分析し、以下の出力形式に従って日本語で要約を出力する
3. **改善提案**: 「このドキュメントをもっと良くするには？」の観点で、構成・誤字に関する改善提案を 3 つ挙げる
4. ファイルが存在しない場合は、その旨を伝えてパスの確認を促す

## 出力形式

必ず次の構成で出力すること:

# タイトル
（ファイル全体の内容を一行で表すタイトル）

## トピック
1. （重要なトピック 1 とその簡潔な説明）
2. （重要なトピック 2 とその簡潔な説明）
3. （重要なトピック 3 とその簡潔な説明）

## 結論
（ファイル全体から導かれる結論・要点を 1〜3 文でまとめる）

## 改善提案
1. （改善提案 1）
2. （改善提案 2）
3. （改善提案 3）

## 注意事項

- トピックは必ず 3 つ挙げること
- 要約はファイルに書かれている内容のみに基づくこと（推測で補わない）
- コードファイルの場合は、目的・主要な処理・依存関係の観点でトピックを選ぶこと
- 改善提案は必ず 3 つ挙げ、**構成**（章立て・並び順・過不足）と**誤字**（誤字脱字・表記ゆれ）の観点に限定すること
- 誤字が見つからない場合は、その旨を明記したうえで構成の提案で 3 つに揃えること
- 改善提案では該当箇所（見出し名や行）を具体的に示すこと
