# 文字数カウント

テキストの文字数を、改行・スペースの扱いが異なる4パターンで同時に出力するスキル。

## なぜ4パターン必要か

「文字数」の定義は文脈によって変わる。出版・原稿の字数制限ではスペースも改行も1文字として数えることが多いが、フォーム入力の文字数制限ではスペースや改行を除外して数える場合がある。どの定義を使うべきかをユーザーに確認する手間を省くため、常に4パターンすべてを出力し、ユーザーが自分の目的に合う数値を選べるようにする。

## カウント対象の定義

- **スペース**: 全角スペース（U+3000 "　"）、半角スペース（" "）、タブ（"\t"）
- **改行**: "\n"、"\r\n"、"\r"（いずれも1文字としてカウントするかどうかの判定対象）

## 使い方

1. 対象のテキストを特定する（ユーザーが貼り付けたテキスト、または指定されたファイル）。
2. ファイルがある場合は `scripts/count_chars.py` にファイルパスを渡して実行する。テキストが直接貼り付けられている場合は、一時ファイルに保存してから渡すか、標準入力（`-`）経由で渡す。

```bash
python3 scripts/count_chars.py <ファイルパス>
# または
echo "対象テキスト" | python3 scripts/count_chars.py -
```

3. **対象がファイルの場合は、カウント結果をそのファイルの一番最後に追記すること。** 元の本文の後ろに区切り線（`---`）を1行挟み、下記の出力例の形式で追記する。チャットへの結果表示だけで終わらせず、必ずファイル自体を更新する。
4. 対象がユーザーが貼り付けたテキスト（ファイルが存在しない）場合は、追記先がないため結果をそのままチャットで提示する。

## 出力例（ファイル末尾への追記イメージ）

```
（元のファイル本文...）

---
改行含む・スペース含む（合計文字数）: 23
改行含む・スペース含まない: 20
改行含まない・スペース含む: 21
改行含まない・スペース含まない: 18
```

## 注意点

- 改行コードが混在するファイル（"\r\n"と"\n"が混在する等）でも、両方を1文字として正しく扱う。
- 改行を除外する処理を行ったあとにスペースを除外する処理を行うため、順序による結果のズレは発生しない。
