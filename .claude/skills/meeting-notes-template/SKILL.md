# 議事録テンプレート

会議の議事録を、決まった雛形（テンプレート）に沿って作成するスキル。

## なぜテンプレートファイルを同梱するか

議事録の構成（見出しの並び、表の形など）は毎回同じであるべきなので、その構造をSKILL.mdの本文に書くのではなく `assets/template.md` という別ファイルに切り出している。これにより:

- SKILL.md自体は短く保てる（雛形が長くなっても本文が膨らまない）
- 雛形だけを直接編集・差し替えできる
- 同じ雛形を他のスクリプトや用途からも再利用できる

これが「テンプレートなど別ファイルを含むスキル」の基本パターン。`scripts/`に実行コード、`references/`に参照ドキュメント、`assets/`に出力に使う素材（テンプレート、画像、フォントなど）を置く、という役割分担を覚えておくとよい。

## 使い方

1. `assets/template.md` を読み込む。
2. 出力先のファイルパスを決める（ユーザー指定があればそれを使う。なければ `議事録_<日付>.md` のような名前を提案する）。
3. テンプレートの内容をそのまま出力先ファイルにコピーする。
4. ユーザーから得られている情報（日時、参加者、議題など）があれば、テンプレートの該当箇所を埋める。情報が無ければプレースホルダーのまま空けておき、ユーザーに埋めてもらう前提でよい。

## 注意点

- テンプレートの構成（見出しや表のカラム）を勝手に変えない。変更したい場合は `assets/template.md` 自体を編集する。
- 出力は既存ファイルを上書きしないよう、ファイル名が重複する場合はユーザーに確認する。
